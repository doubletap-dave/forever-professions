# Working in this pack

This folder is a Polestar community guide pack targeting **World of Warcraft: Forever (`1.60.1`) exclusively**:
`pack.json` describes the pack and `guides/**/*.guide` hold its guides in Polestar's guide format (Format 10).
Every guide ID starts with `forever-professions/`.

Read `docs/MULTI_PROFESSION_RULES.md` before authoring or modifying solo or paired profession guides, and `docs/GITHUB_ACTIONS.md` before changing CI/CD or cutting a release.

## Strict Game Scope

- **World of Warcraft: Forever ONLY.** Do not use Retail, Classic Era, or Season of Discovery recipes, skill thresholds, or mechanics unless verified in the local Forever reference data.
- Keep compiled output (`dist/`, `out/`, `*.lua`, `*.toc`) out of source control — `polestar.guide` rejects `.lua` files outside `locales/<locale>/`.

## Never guess an id, a name or a coordinate

Quest, NPC, object, item, and guide IDs, inn and flight point names, and coordinates come from Polestar's Forever reference data. Look up every one before writing it:

```powershell
polestar find "Brilliant Smallfish" --json
polestar find 6291 --json
polestar find --kind flight --faction Alliance --json
```

## Check until both pass

After every change, repeat until both pass with **0 errors and 0 warnings**:

```powershell
forge guide lint --format json
polestar playtest
```

For paired or `when skill`-gated guides, also verify:

```powershell
polestar playtest --learn "Fishing,Cooking"
```

Then `polestar install` installs the compiled pack into WoW: Forever's AddOns folder, `polestar play` previews it in a browser, and `forge release pack` writes the reproducible zip to `dist/`.

## Author's Material, External Data Sources & License Preservation

In addition to the author's own material, we will reference online databases — such as **Wowhead**, **Questie**, **QuestDB** (QuestieDB), WoW: Forever client tables, and everything available on the internet — to build these guides and ensure they are as effective as possible.

- **Preserve all source licenses:** All licenses and attributions of every external source we reference or build from must be preserved (including `LICENSE-DATA.txt` generated by Forge and explicit credits where required).
- **Author's own prose & routes:** Keep guide prose, route structure, and tips original to this pack (never copy Polestar's own guide text verbatim).
- **Audit and optimize every guide for WoW: Forever:** We will go through all of our guides to make sure every ID, recipe, trainer, skill band, and material count is correct, working in-game, and as optimized as possible for **World of Warcraft: Forever (`1.60.1`)**.
