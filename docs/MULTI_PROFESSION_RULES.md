# Multi-Profession Leveling Rules & WoW: Forever Pairing Guide

> **Strict Game Scope:** World of Warcraft: Forever (`1.60.1`, `Interface: 16001`) **only**.
> Do **not** mix in Retail (Dragonflight/TWW/Midnight Knowledge/Quality systems), Vanilla Classic Era routes, or Season of Discovery supply-box recipes. Every recipe, skill band, Scarce material, Camp Feature, and Legacy Point milestone in this pack targets live WoW: Forever data.

---

## 1. WoW: Forever Profession Mechanics (Verified Baseline)

- **Slots:** 2 Primary Professions (6 Crafting: Alchemy, Blacksmithing, Enchanting, Engineering, Leatherworking, Tailoring; 3 Gathering: Herbalism, Mining, Skinning) + 3 Secondary Professions (Cooking, Fishing, First Aid).
- **Rank Caps:** Apprentice (`1–75`), Journeyman (`75–150`), Expert (`150–225`), Artisan (`225–300`).
- **600+ New Recipes & Rebalanced Bands:** Forever shifts many recipes lower and adds early crafts (e.g. Alchemy elixirs/dyes/acid, Enchanting gear/relics/staves from skill 1, First Aid healing potions, Tailoring reagent bags & gowns). Classic leveling lists are invalid unless re-verified against Forever client tables.
- **Scarce Materials (Bonus Drops):** No dedicated nodes—Uncommon bonus drops from normal nodes/corpses (boosted up to +100% by the *Bountiful Harvest* Legacy perk):
  - **Herbalism:** `Frilled Lichen` (ilvl 25) → Alchemy `Cerulean Dye` (50; 128 recipes, 108 Tailoring) · `Rosecap` (ilvl 45) → Alchemy `Magenta Dye` (130; 62 recipes, 52 Tailoring) · `Stranglevine` (ilvl 60) → Alchemy `Viridian Dye` (230; 15 recipes)
  - **Mining:** `Pyrite` (ilvl 25) → Alchemy `Sulfuric Acid` (50; 42 recipes, 30 Blacksmithing; also 12 direct recipes) · `Bauxite` (ilvl 45) → Engineering `Sandpaper` (130, +1 Bolt of Linen Cloth; 27 recipes, 25 Blacksmithing) · `Pitchblende` (ilvl 60) → Mining `Azerothium Bar` (with Coal; 13 recipes)
  - **Skinning:** `Pristine Leather` (ilvl 25; 126 recipes, 80 LW) · `Pristine Hide` (ilvl 45; 46 recipes, 43 LW) · `Pristine Scale` (ilvl 60; 16 recipes, 12 LW) — consumed directly without a middleman crafter.
- **Legacy Points:** Awarded **only** by the 6 crafting professions at **150, 225, and 300** (3 points per crafting profession; 6 points for a dual-crafter character; 0 points for gathering professions).
- **Camping System (Skill 20+):** Basic Campfire (Cooking 1) hosts up to 3 Camp Features (1 hr shared CD): First Aid Kit (Stamina), Fishing Bowl (+8% all stats), Alchemy Mana Well (MP5), Blacksmithing Sharpening Wheel (Strength), Tailoring Faction Banner (Spirit), Herbalism Incense Candle (Intellect), Leatherworking Tanning Rack / Camp Tent (rested XP), Engineering Reagent Bot.
- **Starter Zone Gathering Manual Quest (Level 3–4):** Grants a free manual for Herbalism, Mining, or Skinning if the character has an open primary slot.
- **Cooked Food Bonus:** Well Fed grants **+5% kill XP** in WoW: Forever, making Cooking + Fishing valuable on every leveling character.

## 3. Multi-Profession Leveling Rules (Polestar Format 10)

These rules govern how `forever-professions` supports **both solo (1 profession)** and **multi-profession (2+ professions simultaneously)** leveling while guaranteeing **0 errors and 0 warnings** in `forge guide lint` and **100% pass rate** in `polestar playtest`.

### Rule 1 — One File Per Single Profession, One File Per Combination (No Monolith Guides)

- **Strict Per-File Granularity:** Every single profession gets its own dedicated `.guide` file (`guides/<profession>.guide`), and every paired profession combination gets its own dedicated `.guide` file (`guides/pairs/<partner>-<anchor>.guide`). **Never** merge multiple solo professions or multiple pairings into one giant guide file—smaller, single-purpose files keep lint diagnostics crisp, diffs reviewable, and Lua 5.1 per-guide constant tables well under limits.
- All 12 solo 1–300 guides remain at `guides/<profession>.guide` with IDs `forever-professions/<profession>` (never break or rename published guide IDs—Polestar refuses uploads that drop live guide IDs).
- Players leveling **one** profession open that profession's solo guide.
- Players leveling **any arbitrary combination** (e.g. Herbalism + Mining + Cooking + First Aid) can either open multiple solo tabs side-by-side (Polestar's `Core/Materials.lua` tracks bags, bank, mail, and pending AH buys across all open tabs) OR pick a dedicated paired-combination guide file under `Paired Routes`.
- Every crafting/secondary solo guide MUST declare both `auction <item> xN` and `collect <item> xN ... gather <Prof> <rank>` (or `gather levels <min>-<max>`) inside each `section`. In **Mix** mode (default), Polestar automatically switches an item from Auction House to Gather whenever the character has the paired gathering profession at the required rank.

### Rule 2 — Compiler Constraint on `section` Headings

Per `forge-guide/src/resolve.rs`:
> `section <Profession> <from>-<to>` checks that **every section in a `.guide` file belongs to ONE profession in strictly rising order**. Mixing `section Fishing ...` and `section Cooking ...` in the same file emits lint warnings and breaks automatic material-count subtraction.

**Therefore, every paired-profession guide MUST follow the Primary-Anchor Section Rule:**

1. **Choose ONE Anchor Profession** for all `section <Anchor> <from>-<to>` lines in the file:
   - For **Gather + Craft** pairs (e.g. `Fishing + Cooking`, `Skinning + Leatherworking`, `Herbalism + Alchemy`, `Mining + Blacksmithing`, `Mining + Engineering`), the **Crafting profession** is the anchor so Polestar's automatic section-start and remaining-craft-material subtraction (`Core/Materials.lua`) work accurately.
   - For **Dual-Craft** pairs (e.g. `Tailoring + Enchanting`, `Tailoring + Alchemy`), the **Producer profession** (the one whose outputs feed the other—e.g. Tailoring for Tailoring+Enchanting, Alchemy for Tailoring+Alchemy) is the anchor.
2. **Interleave the Partner Profession inside each anchor section** using:
   - `train <Partner> <Rank>` (guarded with `when !skill <Partner> <cap>` or placed at natural trainer breakpoints),
   - `skill <Partner> <target>` (for gathering checkpoints before the anchor's craft band),
   - `collect <item> xN anywhere gather <Partner> <rank>` paired with `auction <item> xN` in the same section (so Buy/Mix/Gather modes remain 100% functional and lint-clean!),
   - `learn <spell>` + `craft <spell> xN` (or `until <N>`) for partner intermediate crafts.
3. **Never alternate `section` professions** within one `.guide` file.

### Rule 3 — File Layout, IDs, Folders, and Naming Conventions

| Guide Type | File Path | Guide ID | `category` | `folder` |
| --- | --- | --- | --- | --- |
| Solo 1–300 | `guides/<prof>.guide` | `forever-professions/<prof>` | `Professions` | *(omitted — top-level Professions)* |
| Paired 1–300 | `guides/pairs/<partner>-<anchor>.guide` | `forever-professions/pair-<partner>-<anchor>` | `Professions` | `Paired Routes` |

- Always include `keywords` listing both professions and key synergies (e.g. `keywords fishing, cooking, paired, secondary, fish, well fed`).
- Include `pitch`, `pro`, and `con` headers on paired guides so they render cleanly when offered as route choices via `next`.
- Use `coords era`, `levels 1-60`, `zone Azeroth` unless a guide is faction-exclusive.

### Rule 4 — Step Structure Inside a Paired Guide Section

Every bracket (`section <Anchor> <from>-<to>`) follows a deterministic 6-part cadence:

1. **Rank-Up Gate (Partner & Anchor):** Split `only Alliance` / `only Horde` trainer steps whenever rank caps (`50/75`, `125/150`, `200/225`) are crossed. Include explicit character `level <N>` gates where Forever requires them.
2. **Partner Gathering / Skill Checkpoint:** Advance the partner profession to the minimum skill needed to harvest or craft the bracket's reagents (e.g. `skill Fishing 75`, `skill Herbalism 50`), guarded with `when !skill <Partner> <target>` where appropriate so already-leveled players skip straight ahead.
3. **Materials — Vendor Goods:** `buy <item> xN nearest` for vendor-only supplies (vials, thread, salt, lures, spring water).
4. **Materials — Auction House Fallback:** Single `auction` step listing every AH-buyable reagent for the bracket (`auction <item> xN`). Required by lint whenever `collect ... gather` is used in that section.
5. **Materials — Gather / Partner Feed:** `collect <item> xN ... gather <Partner> <rank>` (or `gather levels <min>-<max>`). Mention Scarce drops to hoard for later brackets or cross-profession crafts in `tip`.
6. **Craft & Intermediates:** `learn` and `craft <spell> xN` (for kept intermediates like bolts, oils, dyes, cured hides) followed by `craft <spell> until <section_end>`.

### Rule 5 — Cross-Profession Linking & Live Detection Conventions

1. **Conditional Synergy Steps (`when skill`):**
   - Solo guides MAY include optional synergy steps or tips gated on a second profession:
     - `when skill Alchemy 50` — craft `Cerulean Dye` / `Sulfuric Acid` instead of buying.
     - `when skill Tailoring 1` — note/craft green items to disenchant in Enchanting.
     - `when skill "First Aid" 1` — remind players of shared cloth pools in Tailoring.
   - Any `when skill` step MUST be verified under `polestar playtest --learn "<ProfA>,<ProfB>"` so both the active and inactive branches pass simulation.
2. **Keep `gather` + `auction` Symmetric:**
   - Every `collect ... gather` inside a section MUST have a matching `auction <item> xN` in the same section (lint warns otherwise).
   - Never put `auction` on a Bind-on-Pickup item (lint error).
3. **Zero Unverified IDs:**
   - Every quest, NPC, object, item, spell, inn, and flight point ID MUST be confirmed via `polestar find <query> --json` against the local Forever reference data (`data/forever/`) and verified clean with `forge guide lint --format json` (0 errors, 0 warnings) and `polestar playtest` (0 stuck, 0 failed).
4. **No Copied Guide Text:**
   - All guide prose, tips, and route text must be original author material. Never copy text from Polestar's built-in guides or third-party sites. Use `next` to hand off to other guides when appropriate.
